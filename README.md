# Devora Autoclicker para Android

Downloads do app (em **Releases**) e os arquivos assinados que ele consulta:

- `atualizacao.txt`: a versão mais recente, com o endereço e a impressão digital (SHA-256) do APK.
- `revogadas.txt`: licenças canceladas (só os identificadores das licenças).

Os dois são assinados com a chave do vendedor: o app recusa qualquer arquivo alterado por outra pessoa.
Cada licença funciona só no aparelho para o qual foi emitida; para comprar, fale com o vendedor.
